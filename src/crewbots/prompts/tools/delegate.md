Give one task to one bot in the crew. It starts at once and runs in parallel with other delegated tasks. goal: the outcome, the context the bot needs, and what done means; it must stand alone. project: the name of the user's project it's about (see Projects); it runs in that project's folder. workspace: a folder or repo within this task's, if neither. in_folder: for a project whose Projects line says it lends its folder, true to have the bot work in the folder itself on a branch of its own instead of a worktree; one task at a time, and the folder must be clean. review_of: the id of a task whose work this one reviews; the reviewer is given a throwaway copy of that task's work it may write in, or, for a Unity project or work done in a project's folder itself, the work itself, read-only (its review brief says which). After delegating, end your turn: results arrive as your next message once none of your tasks are running.
