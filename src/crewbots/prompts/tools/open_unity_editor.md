Open Unity on your task's own worktree of a Unity project, so you can verify your work there through the Unity MCP (the verify-unity skill says how). crewbots starts the Editor of the version the project names, and it connects to the Unity MCP by itself; its first open imports the whole project, which can take a while. You're told when it's connected, so do what doesn't need it meanwhile, or end your turn. crewbots closes it when your work is done with. Not for work in a project's folder itself: that uses the Editor the user has open.
