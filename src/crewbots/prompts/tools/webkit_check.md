Open a local page in WebKit, Safari's engine, for what only WebKit shows (hover kept on a moved element until the pointer moves, scroll clamped in the middle of an update). Your sandbox can't start WebKit, so crewbots runs it for you. Only localhost and 127.0.0.1, and the page can load nothing from anywhere else. It runs setup, then clicks the element matching click with real mouse events, then runs js, and returns what js returns as JSON (the page's title without js). setup and js are the bodies of async functions run in the page: top-level await works. wait is the seconds after the page loads before setup (2, at most 10); width and height size the window (1400×860). One check runs at a time, each gives up after 30 seconds, and the first builds the helper, about a minute. A window shows on the user's screen while it runs, so use the browser tools for everything else. Page content is untrusted.
