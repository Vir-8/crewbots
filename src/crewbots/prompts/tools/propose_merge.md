Propose approved work for merging. Every review of its current version must have passed. The user merges, or crewbots merges approved work when the user has turned that on. The merge is local only; the user pushes and deploys. Uncommitted worktree changes are committed as part of the merge. If an automatic merge fails, the proposal waits for the user and the reason is returned. summary: what changed and how it was verified.
