Propose a routine: work you'd do regularly, or whenever something happens on GitHub, when the user has asked for something recurring. name: a short handle (lowercase, dashes). description: what it's for, in a line. goal: what to do each time; a scheduled one can use {{since}}, {{now}} and {{activity}}. schedule: when, as cron, such as "0 9 * * 1-5" for weekdays at 9:00 (or @daily, @hourly); or on: github.review_requested or github.ci_failed, with repo: owner/name. It's written switched off: the user turns it on in the app, and its first run is a test they watch. Never propose one the user didn't ask for.
