Add a new bot to the crew, when the user asks for one. name: its handle (lowercase letters, digits and dashes), which can't be taken. title and description: what it is, a line each; the description is how the crew routes work to it. instructions: its role card, in markdown: ## Mission, ## Owns, ## Does not own, ## Done means. Optional: display_name, backend (claude or codex), model, effort, access (read_only or workspace_write), network (true or false), can_delegate, mcp (names of the crew's MCP servers; leave out for all of them), skills (names; leave out for all of them). Network only if you have it yourself. Bots can't be removed or changed this way: that's the user's, in the app.
