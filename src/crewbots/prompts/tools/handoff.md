Hand your finished work back, as the HANDOFF in team/protocol.md. Call it once, when you are done. done: what you completed. output: file paths, branches or links to the output. open: anything unfinished or uncertain. needs: what the next step needs, from whoever picks this up. evidence: what you ran or looked at to prove it works and what it showed, one item each (a command and its output, a measurement, a screenshot you shared), so the reviewer can rerun it; and anything you couldn't check, with why. Code work can't be handed back without it. checks: the commands among them that prove it, each run from the work's folder and exiting 0 when it works (a test file, a lint, a script), at most six and quick: crewbots reruns them in a clean copy of the work (without ignored files such as installed dependencies: `uv run` sets itself up, npm needs `npm ci &&` first), in the same sandbox as yours, before a reviewer starts, and if one fails the review round fails with its output. If the work turned out not to be needed (already done elsewhere, covered by a later merge, nothing to change), start done with "dropped:" and the reason: the task is then closed on purpose, its folder removed and its branch kept.
