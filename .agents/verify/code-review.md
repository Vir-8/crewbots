# Code review (frozen)

## Sub-features
- **The inbox:** pull requests asking you, assigned, yours, and your teams'.
- **A pull request:** overview, changes (the diff, windowed, with find), images before and after, and checks.
- **Reviewing:** reviewers' findings, the lead's draft comments, your own drafts, and submit (only you submit).

## How to get to it
"Code review" at the top of the sidebar.

## Driving it with scripts/verify
- The preview has demo pull requests. `?bigdiff=300` gives a 300-file diff, and `?alreadyon` shows "Already on main".

## Gotchas
- Code review is frozen: a change here needs the user's go-ahead first, and must keep its behaviour exactly.
