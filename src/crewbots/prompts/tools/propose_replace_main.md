The chief proposes replacing the branch a project's folder has checked out, and that branch only: it must be the branch a push of it goes to (its upstream names the same branch on the remote), with a rewritten local history that has an identical tree. The daemon reads the live remote tip itself, and the history must contain it, so pushed commits are never rewritten. It refuses while the project has any merge proposed or under way. The user sees the backup ref, the old and new commit counts, the blocking tasks and each check, and chooses whether to press Replace. Only that button moves the branch; never move it yourself. branch: the local branch holding the new history. summary: why, and how you know the trees match.
